How It Works

  1. Select a file from your device.
  2. Enter a strong password (used to derive an AES-256 key via PBKDF2).
  3. Encrypt — the file is encrypted with AES-256-GCM and a random IV/salt.
  4. Download the encrypted .enc file.
  5. To restore, Decrypt using the same password.
